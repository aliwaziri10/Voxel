# Voice Guide — REPLACE WITH BOOK TITLE

Standing style rules for this book, referenced during every editorial_review
pass and every mechanical_qa run. This file exists so a rule discovered on
chapter 11 doesn't stay buried in that chapter's commit message — it goes
here, once, and every later chapter (and every future book, once confirmed
stable across titles) can be checked against it.

This is a Voxel-specific adaptation of the "standing voice/style artifact"
pattern used by the public `scriveno` project, surveyed while researching
other novel-pipeline tooling (see PIPELINE_SPEC.md's "External research"
section) — not a copy of its code, just the same idea: put voice rules in
one file instead of scattering them across history.

## Promotion to series-wide rules

A rule here gets promoted into `novels/EDITORIAL_CHARTER.md` (i.e. applied
to ALL future Voxel novels, not just this one) only after it's held true
across 2+ separate books. Don't promote off a single book's pattern —
that's how you end up over-fitting the charter to one story's quirks.
