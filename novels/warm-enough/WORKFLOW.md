# Warm Enough: drafting rule (every profile, every chapter)

Reason: drafts used to stay in a session scratchpad and were lost when the session ran out of time (ch07). The next profile could not finish what it could not see.

1. The moment a chapter is drafted, BEFORE any checking or fixing, push the raw draft to:
   novels/warm-enough/drafts/chNN_draft.md
2. In the same push, add or update one line for that chapter in:
   novels/warm-enough/STATUS.md
   Example: `ch07: draft pushed, checks pending`
3. Run the checks and fixes. Push the final version to the chapters folder only after the checks pass, then update the line to: `chNN: final`
4. At the start of any session, read STATUS.md first. If a chapter says "draft pushed, checks pending", finish that draft. Do not redraft it.
